Pertanyaan Umum

Ada yang ingin ditanyakan?

Apakah DompetKu benar-benar gratis dan tanpa iklan?

Ya, 100% gratis selamanya tanpa iklan yang mengganggu dan tanpa biaya langganan bulanan. DompetKu dibangun secara independen oleh Farel Rizky P sebagai solusi manajemen keuangan yang jujur dan bersih.

Di mana data keuangan saya disimpan? Apakah aman?

Sangat aman! Seluruh catatan keuangan dan saldo Anda disimpan 100% secara offline di perangkat Anda sendiri melalui IndexedDB browser lokal. Tidak ada server cloud perantara, sehingga tidak ada yang dapat mengintip atau membocorkan data finansial Anda.

Bagaimana cara memasang DompetKu di HP (Android & iPhone)?

Di browser Safari (iOS), ketuk tombol Share lalu pilih "Add to Home Screen". Di Chrome (Android), ketuk menu titik tiga lalu pilih "Install App" atau unduh file APK mandiri di bagian Unduh.

Bagaimana cara memindahkan data saat ganti perangkat?

Masuk ke menu Setelan di dalam aplikasi DompetKu, pilih Ekspor Backup (JSON), lalu kirimkan file tersebut ke HP baru. Di HP baru, cukup pilih menu Impor Backup dan seluruh riwayat Anda akan pulih seketika.

Bagaimana cara menyalakan dan menjaga streak api harian?

Cukup buka aplikasi DompetKu setiap hari dan tekan tombol "Masuk & Nyalakan Api" atau catat transaksi harian Anda. Pertahankan streak untuk menaikkan tingkatan api dari Oranye hingga level Dewa Abadi 1000 Hari!

DompetKu adalah aplikasi keuangan pribadi offline. Dukungan donasi bersifat sukarela untuk mendukung pemeliharaan kode dan penambahan fitur baru.
