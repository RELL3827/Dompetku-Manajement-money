# Website Resmi DompetKu

Landing page & situs resmi aplikasi **DompetKu** dengan gaya antarmuka **Liquid Glass** dan **Editorial Paper** (terinspirasi dari [auralys.my.id](https://auralys.my.id/)).

## 🌟 Fitur Halaman
1. **Dua Pilihan Tampilan**:
   - **Liquid Glass**: Animasi aurora halus, efek cahaya pointer, dan aksen neon emerald/amber.
   - **Editorial Paper**: Nuansa hangat kertas, tipografi serif elegan, dan tekstur minimalis.
2. **Web Audio Melodi Sintesis**:
   - Melodi pentatonik yang bereaksi saat mengetuk logo, mengubah nominal donasi, atau menyalin teks.
   - Tombol toggle Suara di dock bawah.
3. **Traktir Kopi & QRIS Interaktif**:
   - Kode QRIS resmi merchant **RellAppstore** (Farel Rizky P).
   - Efek scanning laser beam animasi.
   - Slider nominal dinamis (Rp1.000 s/d Rp100.000) dan preset tombol nominal cepat.
   - Salin nominal dengan animasi semburan partikel (particle burst).
   - Form pesan untuk pengembang dengan pratinjau langsung dan tombol WhatsApp/Telegram.
4. **Pusat Unduhan & Akses**:
   - Buka Web App (PWA) instan.
   - Unduh APK Android mandiri.
   - Akses via Desktop / Peramban laptop.
   - Modal sapaan ramah sebelum unduh.
5. **Showcase Fitur Utama & FAQ**:
   - 100% Offline & Privat, Streak Api TikTok 8 Taraf, Anggaran 50/30/20, dsb.
   - Pertanyaan umum (FAQ) interaktif.
6. **Floating Bottom Dock**:
   - Navigasi melayang dengan sliding pill indicator untuk berpindah antar seksi dengan mulus.

## 🚀 Cara Menjalankan

### Lokal
Buka file `index.html` langsung di browser mana pun, atau jalankan:
```bash
cd website
npx serve .
```

### Deploy Mandiri
Folder `website/` dapat langsung di-deploy ke Vercel, Netlify, Cloudflare Pages, atau GitHub Pages dengan menghubungkannya ke domain Anda (misal `dompetku.my.id`).
